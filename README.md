# Phishing Email Investigation

## Project Overview
This project was completed as part of my cybersecurity internship. The objective was to investigate a suspicious email and identify possible phishing indicators.

## Investigation Activities
- Examined email headers and sender details.
- Checked SPF, DKIM, and DMARC authentication results.
- Identified suspicious sender and reply-to information.
- Reviewed indicators of compromise (IOCs).
- Assessed potential risks and documented recommendations.

## Tools and Concepts
- Email Header Analysis
- SPF, DKIM, and DMARC
- IOC Identification
- Phishing Detection
- Cybersecurity Analysis

See `Phishing Email Investigation.pdf` in this repository for the investigation report and findings.

## Learning Outcomes
Improved my understanding of email security, phishing indicators, and basic threat investigation.
